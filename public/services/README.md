# Service Background Images

Place the following background images in this directory:

1. **logo-design.jpg** - Branding, logo sketching, vector design, creative desk theme
2. **ai-photo-editing.jpg** - AI face retouch, photo manipulation, before/after editing theme
3. **website-development.jpg** - Code editor, modern UI screens, web layouts theme
4. **error-fixing.jpg** - Debugging code, error logs, fixing bugs, terminal screens theme
5. **video-creation.jpg** - Camera, video timeline, cinematic editing setup theme

## Image Requirements:
- Format: JPG
- Recommended size: 800x600px or larger
- Style: Dark, cinematic, matching the premium agency aesthetic
- Ensure images work well with dark overlay (65% opacity) for text readability
